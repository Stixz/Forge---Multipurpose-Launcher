Quick Tips

Launch

  • Left-click a tile to launch it.
  • Drag and drop tiles to reorder them in the launcher.
  • Keyboard: Tab to focus tiles, Enter or Space to launch, arrow keys to move, Home/End to jump to ends.
  • Press Ctrl+K to open Command Palette for apps and quick actions (Settings, Profiles, Import/Export, tray toggle). Type to filter, use Up/Down arrows to choose, Enter to run, and Esc to close.
  • The search bar filters tiles by name, category, or description in real time.
  • Use the left Category rail to jump between groups instantly without typing.

Settings

  • Changes in Settings are not kept until you click Save Settings.
  • To set a Global Hotkey: click the hotkey field in Settings and press your desired key combination (e.g. Ctrl+Alt+F). Press Backspace or Delete to clear.
  • Enable Start on Boot in Settings to have Forge launch automatically when Windows starts.
  • Choose a Card Size Preset (Compact / Comfortable / Large) in Settings to resize launcher tiles. Use Custom for precise width and height control via sliders.
  • You can lock Settings with a PIN in the Security section. After 5 failed unlock attempts the PIN field locks for 30 seconds.

Profiles & App Editor

  • Use Profiles to maintain separate app layouts for work, gaming, streaming, or any context.
  • Right-click any tile to open the App Editor with that app pre-selected.
  • Use Category in the App Editor to group apps; groups appear as section headers in the main view.
  • App types: Web opens a URL in your default browser; Local runs a file/folder target; Steam launches a game via Steam using its App ID.
  • New App in the App Editor clears the form so you can add a fresh entry without affecting the currently selected app.

Config And Tray

  • Export Config saves all your apps, profiles, and settings to a JSON file for backups or sharing.
  • Import Config shows a preview letting you Replace your current setup or Merge imported profiles and apps (duplicates are skipped automatically).
  • Enable Persist in system tray if you want closing the window to hide Forge instead of quitting it fully.
  • When Forge is in the tray, click the tray icon to reopen it, or right-click for the tray menu (Exit).
