# Forge
The multipurpose launcher at the heart of the Ravenforge ecosystem.

Forge is a flexible, modular launcher designed to unify tools, workflows, and creative utilities under one roof.  
It’s the central anvil — the place where everything begins.

## Purpose
- Launch tools, scripts, and modules from a single interface
- Provide a customizable hub for personal or studio workflows
- Serve as the foundation for future Ravenforge utilities

## Philosophy
Forge is meant to be remixed.  
If you want to adapt it, extend it, or build your own launcher from it — do it.  
This is the official Ravenforge build, but the forge is open.
